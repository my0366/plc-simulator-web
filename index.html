사용법 · 명령어 · 단축키
  • 명령어 입력 입력 창에 LD X0 처럼 쓰고 Enter를 누릅니다. 창은 열린 채로 다음 명령어를 받고, Esc로 닫습니다. LD/LDI 첫 접점, AND/ANI 직렬, OR/ORI 병렬, OUT/SET/RST 출력. 타이머와 카운터는 OUT T0 K30(3초), OUT C0 K5(5회)처럼 입력합니다.
  • 직렬끼리 병렬 연결 먼저 LD X0 → AND X1으로 위쪽 회로를 만들고, LD X2 → AND X3으로 아래쪽 가지를 만든 뒤 ORB로 합칩니다. 이어서 OUT Y0을 입력하면 한 출력으로 모입니다. 접점 하나만 병렬로 붙일 때는 OR Y0(지금까지의 회로 전체와 병렬)을 씁니다.
  • 행 추가 ⌘ 또는 Ctrl + Enter로 현재 행 아래에 빈 행을 만들고, 바로 명령어를 이어서 입력합니다. 예: LD X0 → OR Y0 → ANI X1 → OUT Y0.
  • 이동·수정 방향키로 커서를 옮기고, 접점 위에서 Enter(또는 더블클릭)를 누르면 입력 창에 명령어가 채워져 그 자리를 수정합니다. Delete 삭제, ⌘/Ctrl + Backspace 현재 행 삭제. 커서가 래더 위에 있을 때 영문자를 치면 입력 창이 열립니다.
  • 되돌리기 ⌘/Ctrl + Z로 되돌리고, ⌘/Ctrl + Shift + Z(또는 Ctrl + Y)로 다시 실행합니다. 입력 창이 비어 있을 때도 동작합니다.
  • 저장 편집 내용은 이 브라우저에 자동 저장됩니다. “파일로 저장”으로 .json 파일을 보관하고 “파일 열기”로 다시 불러올 수 있습니다.
  • 타임차트 예상에서 X 입력의 역할과 ON/OFF 시각을 정한 뒤 예상 버튼을 누르면, 지정한 입력 순서로 래더를 시뮬레이션합니다. 입력 일정은 이 브라우저에 저장됩니다.
  • 유지는 누를 때마다 ON/OFF가 바뀌는 스위치, 푸시는 누르는 동안만 ON인 버튼입니다. 입력 아래 버튼으로 바꿉니다.
  • 접점이나 코일을 클릭해 선택하고, “수정” 버튼이나 Enter로 입력 창을 엽니다. 타이머 설정값도 OUT T0 K30처럼 이 창에서 바꿉니다.
  • 프로그램은 50ms마다 위에서 아래로 실행됩니다. STOP을 누른 뒤 “한 번 실행”을 누르면 스캔을 한 단계 진행합니다.
  • a접점(NO)은 신호가 ON일 때 닫히고, b접점(NC)은 신호가 OFF일 때 닫힙니다. 타이머 설정값은 0.1초 단위입니다.
